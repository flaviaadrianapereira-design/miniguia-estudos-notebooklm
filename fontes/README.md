# Fontes

Este diretório reúne as fontes utilizadas no projeto de Educação Financeira para Iniciantes.

## Fontes utilizadas

1. Caderno de Educação Financeira – Gestão de Finanças Pessoais — Banco Central do Brasil.

2. Folder Cidadania Financeira – Orçamento Pessoal — Banco Central do Brasil.

3. Portal do Investidor — Comissão de Valores Mobiliários (CVM).

## Objetivo

Utilizar fontes confiáveis para estudar conceitos básicos de educação financeira com auxílio do NotebookLM.
