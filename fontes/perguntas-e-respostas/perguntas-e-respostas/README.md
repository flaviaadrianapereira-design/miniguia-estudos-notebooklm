# Perguntas e Respostas

Este diretório reúne as perguntas e respostas geradas durante os estudos de Educação Financeira para Iniciantes com apoio do NotebookLM.

## Objetivo

Registrar as principais perguntas feitas durante o estudo e as respostas fundamentadas nas fontes utilizadas.

## Temas estudados

- Necessidade x desejo
- Sonho x projeto
- Orçamento pessoal
- Consumo consciente
- Organização financeira
- Poupança  investimentos
- Planejamento  financeiro
- Planejamento para o futuro
